# AI agent entry point

Use this entry point for any AI agent working in this project. Follow the project root `AGENTS.md` and preserve application-specific instructions.

Before the first Xizot code change in each task, read every Xizot skill entry point below at least once, even when only one will own the implementation. Then follow the relevant skill's workflow and open its references only when the task requires them. Do not start coding from generic framework habits.

- [Xizot workflow](skills/xizot-design-system/SKILL.md)
- [Page builder](skills/xizot-page-builder/SKILL.md)
- [Forms](skills/xizot-forms/SKILL.md)
- [Shared system](skills/xizot-system/SKILL.md)
- [Quality](skills/xizot-quality/SKILL.md)

Read [React implementation rules](rules/react.md) and the application's own coding conventions before editing code.

- For new application pages, follow [feature architecture](skills/xizot-design-system/references/feature-structure.md) and the page-builder route before coding.

Resolve component locations and imports from the current project using [source ownership](skills/xizot-design-system/references/source-ownership.md). Preserve unrelated user files and configuration.
