# Xizot Interaction

Use this skill when a screen needs clear behavior, not just static layout.

## Required Reference

Read [references/interaction-patterns.md](references/interaction-patterns.md) before building action groups, toolbars, filters, menus, tabs, dialogs, sheets, drawers, or confirmations.

## Defaults

- Primary actions are visible and stable.
- Secondary actions are grouped without competing.
- Rare actions live in menus.
- Destructive actions require clear affordance and confirmation when irreversible.
- Async actions show pending state and result feedback.
