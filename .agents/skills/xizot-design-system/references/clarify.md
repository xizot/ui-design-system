# Clarify Command

Use for UX copy, labels, actions, validation, and empty/error states.

## Tone

For Vietnamese product UI:

- concise
- direct
- operational
- polite without being verbose
- consistent terms across filters, table headers, buttons, and errors

## Labels

- Buttons should name the action: `Tạo mới`, `Lưu`, `Hủy`, `Áp dụng`, `Xóa`, `Xuất file`, `Làm mới`.
- Empty states should say what happened and what action is available.
- Errors should say what failed and what the user can do next.
- Filter placeholders should be searchable and specific when useful.

## Avoid

- Marketing copy inside operational UI.
- Mixed English/Vietnamese unless the product already does that.
- Long button labels that will overflow on mobile.
- Vague labels such as `OK`, `Submit`, `Click here`, or `Manage`.
