# Xizot UX

Use this skill to make interfaces easier and safer to operate. A page is not finished until users can understand where they are, what changed, and what to do next.

## Required Reference

Read [references/ux-decision-model.md](references/ux-decision-model.md) for UX flow, cognition, forms, feedback, and error prevention.

## Defaults

- Prefer recognition over recall.
- Show current location, current state, active filters, selected rows, and pending actions.
- Keep validation close to fields.
- Use confirmation for irreversible actions.
- Empty states should include a next step when one exists.
