# Type Hierarchy

## Hierarchy Stack

Use this order before adding decoration:

1. Content priority
2. Position and grouping
3. Type size
4. Font weight
5. Color contrast
6. Spacing

## Product UI Defaults

- Page title: clear and compact, not hero-sized.
- Section headings: small but strong enough to scan.
- Table cells: readable density, usually component default or `text-sm`.
- Metadata: muted only when secondary.
- Badges: short labels that fit at small sizes.

## Labels And Actions

- Put the meaningful word first.
- Use verbs for actions.
- Use nouns for field labels.
- Placeholder text supports labels; it does not replace labels.
- Error text tells what failed and how to fix it.

## Vietnamese UI

Prefer stable operational labels:

- `Tạo mới`
- `Lưu`
- `Hủy`
- `Áp dụng`
- `Xóa`
- `Làm mới`
- `Tìm kiếm`
- `Không có dữ liệu`
- `Đang tải...`

Avoid long button labels. Put explanation in helper text, tooltip, or body copy.
