# Xizot Typography

Use this skill when type hierarchy or readable density determines whether a page feels professional.

## Required Reference

Read [references/type-hierarchy.md](references/type-hierarchy.md) before changing type scale, labels, headings, table typography, or dense UI copy.

## Defaults

- Use the existing compact scale: `text-xs`, `text-sm`, `text-md`, `text-lg`, `text-xl`.
- Avoid viewport-scaled type and negative letter spacing.
- Make hierarchy with size, weight, color contrast, spacing, and alignment.
- Keep muted text secondary.
- Keep Vietnamese product labels short and stable.
