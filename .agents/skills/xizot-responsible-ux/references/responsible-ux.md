# Responsible UX

## Principles

- Users should understand consequences before acting.
- Defaults should be safe and reversible where possible.
- Critical actions should be deliberate, not accidental.
- Copy should inform, not manipulate.
- Error recovery should be clear and practical.

## Destructive Actions

- Name the object affected.
- Explain irreversible impact.
- Require confirmation when data loss or broad impact is likely.
- Keep cancel path visible.
- Provide undo only when it truly works.

## Consent And Choice

- Do not make decline/cancel harder to find than accept/continue.
- Avoid shaming or pressure copy.
- Do not preselect risky choices without domain justification.
- Make permission boundaries explicit.

## Error Recovery

- Tell users what failed.
- Preserve their work.
- Offer retry or next step where possible.
- Distinguish validation errors from system errors.

## Product Trust

Operational UI should feel reliable: consistent labels, stable placement, visible state, clear consequences, and no surprise side effects.
