# Xizot Responsible UX

Use this skill when product UI can affect trust, consent, irreversible data changes, user effort, or decision quality.

## Required Reference

Read [references/responsible-ux.md](references/responsible-ux.md) before designing destructive flows, permission flows, consent, billing-like decisions, notifications, defaults, or recovery states.

## Defaults

- Make consequences visible before irreversible actions.
- Do not hide cancellation, decline, or undo paths.
- Use honest copy; do not pressure users with manipulative labels.
- Permission and unavailable states should explain scope and next step.
- Recovery matters as much as prevention.
