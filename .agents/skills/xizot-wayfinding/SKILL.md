# Xizot Wayfinding

Use this skill when users need to understand where they are, what scope they are viewing, and how to move through the product without guessing.

## Required Reference

Read [references/wayfinding-model.md](references/wayfinding-model.md) before changing navigation, page titles, breadcrumbs, tabs, sidebars, filters, or cross-page flows.

## Defaults

- Page title, active navigation, and current scope must agree.
- Breadcrumbs show hierarchy; tabs show peer views; filters show data scope.
- Empty states should explain the current scope and next available action.
- Search/filter placement should make the affected region obvious.
